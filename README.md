This project was developed to practice frontend development and create a real-world wedding invitation website. It focuses on clean design, responsive layouts, and creating an engaging experience for wedding guests.

🚀 Installation

Clone the repository:

git clone https://github.com/ShahrozYousaf/web-wed-card.1.git

Go to the project folder:

cd web-wed-card.1

Open index.html in your browser.

🎯 Purpose

The goal of this project is to provide a modern digital wedding card experience that can be shared online instead of traditional printed invitations. Digital invitations are easy to share, customizable, and accessible from any device.
